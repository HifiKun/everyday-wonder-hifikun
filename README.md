One sentence, up to 200 characters, on a small moment of wonder in everyday life. The program writes that sentence to `/output/entry.txt`, where an AI judge compares it two at a time against the other entries and picks the one that makes the everyday strange and new.

## Run it

```sh
node main.ts
```
